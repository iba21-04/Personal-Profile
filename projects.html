🍕 Campus Cravings - Food Delivery for Students

Timeline: Mobile app development

Inspiration

Campus life is busy, and many students struggle to balance part-time jobs with classes. We wanted to create a flexible way for students to earn money while helping others get food delivered conveniently—without disrupting their studies.

What it does

  • Earn while delivering: Students can earn money by delivering food to fellow students while getting their own.
  • Convenient ordering: Students who need food can place an order from anywhere on campus and have it delivered straight to their seat.
  • Campus-exclusive: The system is limited to campus, making it fast and reliable.

Essentially, it provides a second way of earning for students who don't want a traditional part-time job and offers convenience for those receiving food.

How we built it

  • Front-end: Mobile interface with an intuitive design for ordering and tracking food.
  • Back-end: Handled student accounts, orders, and payments.
  • APIs: Used the Leaflet API for mapping delivery locations on campus.
  • Payment & rewards: Implemented a system to manage payments and earnings for student deliverers.

💰 Coin Coach - Crypto Learning Platform

Timeline: Web platform development

Inspiration

Crypto is becoming the future of finance, but when we first tried using platforms like Binance, we felt overwhelmed and confused. The crypto space is full of complicated terms, risky actions, and scams and there aren't enough beginner-friendly resources that teach people by doing. That inspired us to build CoinCoach, a fun and educational platform that helps users understand crypto safely through interactive learning.

What it does

CoinCoach is an educational crypto learning platform that teaches users how to invest and stay safe using:

  • Beginner-friendly tutorials
  • Interactive simulations where users invest with fake money
  • Realistic market graphs and trends that go up and down based on scenarios
  • An AI chatbot that explains concepts, gives guidance, and answers crypto questions in simple terms

CoinCoach makes learning crypto feel like a game while still teaching real skills like risk management, decision-making, and scam awareness.

How we built it

  • Frontend: Next.js + React with modern dark-mode crypto design
  • Styling: Tailwind CSS for responsive design
  • Charts: Advanced charting tools for real-time trend graphs
  • AI: Gemini API integration for smart guidance and scenario-based simulations
  • Collaboration: GitHub for team coordination

Structured like a real product: modular pages, strategy selection, simulation engine, and feedback reporting.

🎵 Road Rhythm - Car Stereo System

Timeline: September 2025 – December 2025

Tech Stack: BeagleYAI, Bluetooth, IoT Sensors, Web Interface

Project Highlights

  • Bluetooth Car Stereo: Built a Bluetooth-enabled car stereo on the BeagleYAI board, enabling smartphone playback and feature control via a custom web interface, with joystick navigation and rotary encoder volume adjustment.
  • Sensor Integration: Integrated an accelerometer, temperature sensor, and magnetometer to provide live speed, temperature, and directional data and displayed real-time information on a 16×2 LCD screen.
  • Music-Responsive Lighting: Implemented music-responsive LED lighting by processing the audio signal with Fourier transforms to extract frequency components and drive synchronized visual effects.

🛒 Cart Quest - Gamified Grocery Shopping

Tech Stack: HTML, CSS, JavaScript

Inspiration

The inspiration came from the everyday experience of shopping for groceries and cooking meals. We thought: what if picking ingredients and cuisines could feel like a fun, interactive game rather than a chore? By combining the idea of cuisines, dishes, and grocery shopping into a gamified experience, we aimed to make learning about food cultures and cooking more exciting.

What it does

CartQuest is an interactive, gamified grocery shopping experience. Players start by choosing a cuisine (Indian, Italian, Chinese, or Mexican), then pick a dish. From there, they explore a virtual grocery store, picking up ingredients by clicking with icons. The game turns ordinary shopping into a fun adventure with glowing buttons, animated aisles, and engaging interactions.

How we built it

  • Frontend: HTML, CSS, JavaScript
  • Animations: CSS keyframes for floating effects, glowing buttons, and background animations
  • Dynamic Dishes: JavaScript event listeners to load dish options when a cuisine is selected
  • Prototype Store: Drag-and-drop functionality simulates picking groceries and adding them to a cart
